  * **Lề phải (Right margin):** **2.0 cm**

## 5. ĐOẠN MÃ PYTHON-DOCX MẪU (CODE SNIPPETS)

### Cài đặt lề trang & Style mặc định:
```python
import docx
from docx.shared import Cm, Pt, RGBColor
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml import OxmlElement
from docx.oxml.ns import qn

doc = docx.Document()

# 1. Căn lề in chuẩn (Top 3.0cm, Bottom 3.0cm, Left 3.0cm, Right 2.0cm)
section = doc.sections[0]
section.page_width = Cm(21.0)
section.page_height = Cm(29.7)
section.top_margin = Cm(3.0)
section.bottom_margin = Cm(3.0)
section.left_margin = Cm(3.0)
section.right_margin = Cm(2.0)
section.header_distance = Cm(1.27)
section.footer_distance = Cm(1.27)

# 2. Cấu hình style Normal (Times New Roman, 13pt, 1.5 lines, Justify, after 4pt)
normal_style = doc.styles["Normal"]
normal_style.font.name = "Times New Roman"
normal_style.font.size = Pt(13.0)
normal_style.font.color.rgb = RGBColor(0, 0, 0)
normal_pf = normal_style.paragraph_format
normal_pf.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY
normal_pf.line_spacing = 1.5
normal_pf.space_before = Pt(0)
normal_pf.space_after = Pt(4.0)

# Cấu hình rFonts trong XML để đảm bảo hiển thị đúng Times New Roman trên mọi bản Word
rPr = normal_style.element.get_or_add_rPr()
rFonts = OxmlElement('w:rFonts')
rFonts.set(qn('w:ascii'), 'Times New Roman')
rFonts.set(qn('w:hAnsi'), 'Times New Roman')
rFonts.set(qn('w:cs'), 'Times New Roman')
rPr.append(rFonts)
```

### Thêm đoạn văn bản xuôi thụt đầu dòng 1.27 cm:
```python
p = doc.add_paragraph()
p.paragraph_format.first_line_indent = Cm(1.27)
p.paragraph_format.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY
p.add_run("Trong kỷ nguyên số hiện nay, xử lý ảnh y tế đóng vai trò then chốt...")
```

### Thêm Caption Bảng (TRÊN) và Caption Hình (DƯỚI):
```python
# Caption Bảng (TRÊN bảng)
p_tbl = doc.add_paragraph()
p_tbl.paragraph_format.alignment = WD_ALIGN_PARAGRAPH.CENTER
p_tbl.paragraph_format.space_before = Pt(6)
p_tbl.paragraph_format.space_after = Pt(4)
r_tbl = p_tbl.add_run("Bảng 6.1: So sánh đối đầu hiệu năng định lượng giữa Watershed và Region Growing")
r_tbl.font.name = "Times New Roman"
r_tbl.font.size = Pt(11.5)
r_tbl.italic = True

# Caption Hình (DƯỚI hình)
p_fig = doc.add_paragraph()
p_fig.paragraph_format.alignment = WD_ALIGN_PARAGRAPH.CENTER
p_fig.paragraph_format.space_before = Pt(4)

r_fig = p_fig.add_run("Hình 4.1: Minh họa 6 bước trung gian của thuật toán bóc sọ não")
r_fig.font.name = "Times New Roman"
r_fig.font.size = Pt(11.5)
r_fig.italic = True
```
